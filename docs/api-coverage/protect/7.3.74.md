## Notes

- OpenAPI 3.1.0 with 74 operations and 302 component schemas. info.version is "0.0.0"; the portal labels this document v7.3.74. The portal label is the revision of record.
- OpenAPI operations carry no operationId; inventory keys are "<METHOD> <path>".
- Servers: "UniFi API Cloud Connector" (forbidden by design) and "Local Console" https://{consoleIP}/proxy/protect/integration.
- Documented WebSocket update surfaces: GET /v1/subscribe/devices and GET /v1/subscribe/events (spec §11 native events, Phase 3).
- Required Ports Reference lists TCP 7443 "REST API (HTTPS)" for Protect. That is an application service port, not the documented integration base URL above (spec §4.1: do not confuse service ports with the integration API).
- Sensitive surfaces: camera snapshot (image), RTSPS stream URLs, talkback session URL, user/identity-user e-mail, permanent microphone disable (irreversible).
- Observed 2026-11-11 (see network/11.0.97; not stated by the vendor): a key created under Integrations in UniFi Network also authorises this API on the same console.
- The current official release on 2026-11-11: the owner's console runs 7.3.74 and UniFi OS offers no newer release, while the developer portal documents 7.4.96. Operations this revision documents are built from it and also serve later 7.x consoles; api:reconcile checks that every later difference is additive (ADR 0019 §7).
