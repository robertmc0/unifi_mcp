## Notes

- OpenAPI 3.1.0 with 83 operations and 321 component schemas. info.version is "0.0.0"; the portal labels this document v7.4.96. The portal label is the revision of record.
- OpenAPI operations carry no operationId; inventory keys are "<METHOD> <path>".
- Servers: "UniFi API Cloud Connector" (forbidden by design) and "Local Console" https://{consoleIP}/proxy/protect/integration.
- Documented WebSocket update surfaces: GET /v1/subscribe/devices, GET /v1/subscribe/events and (new in 7.4.96) GET /v1/subscribe/updates?modelKeys=… (spec §11 native events). Their message schemas are documented: deviceEvent, eventAdd/eventUpdate, modelUpdateEvent. Event removals are not sent.
- Required Ports Reference lists TCP 7443 "REST API (HTTPS)" for Protect. That is an application service port, not the documented integration base URL above (spec §4.1: do not confuse service ports with the integration API).
- Sensitive surfaces: camera snapshot (image/jpeg), RTSPS stream URLs, talkback session URL, user/identity-user e-mail, permanent microphone disable (irreversible), arm/disarm of arm profiles and external arm profiles, siren and relay outputs.
- Observed 2026-11-11 (see network/11.0.97; not stated by the vendor): a key created under Integrations in UniFi Network also authorises this API on the same console.
- Changes from v7.3.74 (reviewed 2026-11-11): 9 operations added (external arm profiles: list, get, create, update, delete, arm, disarm; POST /v1/speakers/{id}/stop-siren; GET /v1/subscribe/updates), none removed. The only change to an existing operation is a documented 409 on POST /v1/cameras/{id}/talkback-session ("another talkback session is already in progress").
