# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers, and keep discussion focused
on the work. Harassment and personal attacks are not tolerated.

**Enforcement contact:** to be set before the repository is made public (tracked in Phase 5
of [docs/phase-checklist.md](docs/phase-checklist.md)). Until then, contact the repository
owner privately.
