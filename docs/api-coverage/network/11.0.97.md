## Notes

- OpenAPI 3.1.0, info.version 11.0.97, 73 operations, 380 component schemas.
- OpenAPI declares two servers: "UniFi API Cloud Connector" (api.ui.com, forbidden by design, spec §1.2) and "Local Console" https://{consoleIP}/proxy/network/integration. Adapters use only the local server.
- OpenAPI declares no securitySchemes; the X-API-KEY header is specified in portal prose and the developer.ui.com llms.txt index.
- The OpenAPI documents only 2xx responses. The Error Handling page documents the error body: statusCode, statusName, code (e.g. api.authentication.missing-credentials), message, timestamp, requestPath (e.g. /integration/v1/sites/123), requestId (UUID, for 500s).
- Documented action enums: device action RESTART; port action POWER_CYCLE; client actions AUTHORIZE_GUEST_ACCESS and UNAUTHORIZE_GUEST_ACCESS.
- Credential-bearing fields in schemas: Hotspot voucher `code`; Wi-Fi pre-shared key `passphrase`.
- The developer portal publishes Network API documentation for versions 9.1.120 through 11.0.97; older consoles may expose fewer operations (spec §19).
